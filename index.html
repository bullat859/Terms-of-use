01 AccessibilityService API Disclosure

EDGE uses Android's AccessibilityService API strictly to perform user-configured navigation gestures (such as Back, Home, Recent Apps, Pull Down Notifications, Open Quick Settings, Lock Screen, Power Dialog, and Split Screen).

  • No Data Collection: The Accessibility Service NEVER reads, collects, monitors, logs, stores, or transmits sensitive personal data, keystrokes, passwords, financial details, messages, or screen contents.
  • User Control: Enabling Accessibility is entirely voluntary and can be enabled or revoked at any time via Android system settings.

02 Microphone & Voice Assistant Privacy

The voice command assistant parses spoken trigger phrases using on-device, rule-based algorithms to set alarms, launch navigation, or execute gestures.

  • Local Audio Processing: Voice input is never uploaded to remote cloud servers, never monitored for behavioral profiling, and never sold to third parties.
  • Audio Focus Management: The app manages audio focus during speech synthesis to prevent audio bleed and protect your listening experience.
